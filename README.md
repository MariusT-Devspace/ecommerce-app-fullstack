
# ecommerce-app-fullstack

Ecommerce web app built with ASP.Net Core (backend) and Angular (frontend). This project is a work in progress and was built to showcase my knowledge in front end and back end technologies.

## Overview

This project is a fullstack responsive ecommerce web application. It allows users to log in, browse products, and save items to wishlists. It also provides a way for admin users to manage products and categories. The backend is developed using ASP.Net Core, and the frontend uses Angular.

## Features

- User authentication and authorization
- Create, edit, and delete wishlist items
- Responsive UI with Angular
- RESTful API with ASP.Net Core
- GPL-3.0 licensed

## Tech Stack

- **Frontend:** Angular (TypeScript)
- **Backend:** ASP.Net Core
- **License:** GNU GPL v3.0

## Getting Started

### Prerequisites

- Node.js & npm
- .NET SDK (ASP.Net Core)
- Angular CLI

### Installation

#### Backend

1. Clone the repository:
   ```bash
   git clone https://github.com/MariusT-Devspace/ecommerce-app-fullstack.git
   cd ecommerce-app-fullstack
   ```
2. Navigate to the backend folder (if applicable) and restore dependencies:
   ```bash
   dotnet restore
   ```
3. Run the backend server:
   ```bash
   dotnet run
   ```

#### Frontend

1. Navigate to the Angular app directory:
   ```bash
   cd path-to-angular-app
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the Angular development server:
   ```bash
   ng serve
   ```

### Usage

Open your browser and go to `http://localhost:4200` to access the app.
